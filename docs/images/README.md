# Screenshots for the README

Drop images here and uncomment the matching block in [../../README.md](../../README.md).

Suggested set, in the order the README expects them:

| File | What it should show |
|---|---|
| `drift.png` | The Drift view: the Figma frame beside the live page |
| `findings.png` | The triaged findings list |
| `fix.png` | A proposed patch with the Approve control visible |
| `run.gif` | One run end to end, which can replace all three |

Capture at a desktop width (around 1440px) in whichever theme reads better,
and crop to the content rather than the whole browser window.

Keep each file under about 1MB so the README stays quick to load. A GIF of a
run is the most persuasive single asset, since the per-agent progress is
visible as it happens.
